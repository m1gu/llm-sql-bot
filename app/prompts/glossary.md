Cannabis Lab Glossary (Draft)
============================

- Customer → Client, Account, License Holder
- Sample → Specimen, Submission, Batch Item
- Test → Analysis, Assay, Panel
- Batch → Production Batch, Extraction Lot, Grow Lot
- Matrix Type → Product Type, Sample Matrix, Material Type
- Has Report → Certificate Issued, COA Ready, Lab Report Available
- Date Created → Intake Date, Submission Date, Logged Date
- Date Completed → Completion Date, Finalized Date, Result Date
- Order → Work Order, Submission Order, Request
- Sample Weight → Net Weight, Reported Weight, Submitted Weight
- State (status) → Workflow Status, Processing Stage, Lifecycle State
- Label Abbr → Analyte Code, Method Abbreviation, Test Code
- Title (test title) → Assay Name, Panel Name, Method Name
- Raw Payload → Source JSON, Metadata Blob, Ingested Payload
- Custom Formatted ID → Lab ID, External ID, Tracking ID
- Has Report (test/samples) → COA Complete, Reporting Done, Certificate Generated
