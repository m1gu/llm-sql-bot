Objetivo

Construir, en local, un chatbot de datos que responda preguntas en lenguaje natural sobre una base PostgreSQL pequeña (6 tablas, ~10k filas máx por tabla) usando:

Python (stock)

Ollama con Mistral 7B Instruct

LangChain (orquestación + SQL Agent)

FastAPI (API)

Slack Bot (Bolt para Python)

Observabilidad (logs/metrics), prompts con “schema awareness”, y controles de seguridad (solo lectura, guardas de SQL, rate limit).

Cada fase es un paso pequeño y funcional con entregables y un prompt sugerido para Codex (copiar/pegar).

Prompts base (para inyectar en el sistema)

app/prompts/system_base.md

Eres un analista experto en PostgreSQL.
Objetivo: responder preguntas de negocio usando SOLO consultas SELECT contra la BD.
Reglas:
- No ejecutes DDL/DML (DROP/UPDATE/DELETE/INSERT/ALTER).
- Si la pregunta es ambigua, pide una aclaración breve antes de consultar.
- Usa nombres de tablas/columnas EXACTOS del esquema.
- Incluye siempre LIMIT si el resultado puede ser grande.
- Si la consulta falla, analiza el error y corrige en un segundo intento.
Formato de salida intermedia (oculta): genera primero la SQL, luego ejecuta, luego redacta respuesta clara y breve, con cifras y rango de fechas si aplica.


app/prompts/schema.md (generado en Fase 5)
Resumen de tablas/columnas/relaciones (auto-generado).

app/prompts/glossary.md
Sinónimos de negocio → nombres reales (editado a mano).
